# Презентації до захисту GamesInfoSys

У каталозі підготовлено дві Markdown-презентації за композицією наданих PDF-зразків:

- `01_gamesinfosys_chub_style.md` - розгорнута версія на 22 слайди: мета, завдання, актуальність, IDEF0, вимоги, UML, архітектура, модель даних, інтерфейс, тестування, порівняння та висновки.
- `02_gamesinfosys_leonov_style.md` - компактна версія на 16 слайдів із темним оформленням і стислим викладом матеріалу.
- `assets/` - реальні скриншоти розробленого застосунку GamesInfoSys.

## Як використовувати

Файли сумісні з Marp. Для попереднього перегляду можна встановити розширення **Marp for VS Code** і відкрити режим Markdown Preview.

Приклад експорту:

```powershell
marp 01_gamesinfosys_chub_style.md --pdf
marp 02_gamesinfosys_leonov_style.md --pdf
```

Діаграми записано мовою Mermaid. Якщо вибраний експортер Marp не підтримує Mermaid, їх потрібно експортувати в PNG або SVG з додатка А та замінити Mermaid-блоки посиланнями на зображення.

Перед захистом замініть службові поля:

- `[ПІБ студента]`;
- `[шифр групи]`;
- `[ПІБ керівника]`;
- `[посада, науковий ступінь керівника]`.
