## Abstract

The object of the study is the processes of searching, aggregating, storing, and presenting video game information.

The purpose is to design and implement GamesInfoSys, a web-based information system that combines game metadata, store offers, regional links, and approximate UAH price conversion.

The system is implemented using .NET 10, ASP.NET Core Razor Pages, Entity Framework Core, SQLite, external HTTP services, and a local demo dataset.

## Вступ

Інформація про відеоігри розподілена між каталогами, цифровими магазинами, агрегаторами знижок і локальними торговельними ресурсами. Користувачеві потрібно зіставляти назви, платформи, регіони й валюти вручну. Це збільшує час пошуку та ускладнює вибір пропозиції.

Метою роботи є проєктування та розробка GamesInfoSys - інформаційної системи, яка формує єдину картку гри та агрегує доступні пропозиції.

Для досягнення мети потрібно проаналізувати предметну область, побудувати моделі, сформувати вимоги, спроєктувати архітектуру і дані, реалізувати застосунок та виконати тестування.
