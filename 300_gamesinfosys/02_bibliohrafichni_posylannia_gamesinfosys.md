# БІБЛІОГРАФІЧНІ ПОСИЛАННЯ ДЛЯ РОБОТИ ПРО GAMESINFOSYS

Джерело-основа: `dstu-8302-2015.pdf`.

Цей документ є практичною пам'яткою для оформлення посилань у пояснювальній записці GamesInfoSys. Він не замінює офіційний текст ДСТУ 8302:2015.

## 1 Загальні правила

- джерела нумерують у порядку першого згадування в тексті;
- посилання подають у квадратних дужках: `[1]`, `[2, с. 15]`, `[3-5]`;
- опис має дозволяти ідентифікувати та знайти джерело;
- назву, авторів, рік і URL беруть із самого джерела;
- для онлайн-ресурсів зазначають URL і дату звернення;
- для документації програмних платформ бажано вказувати назву розділу;
- один формат пунктуації потрібно використовувати в усьому списку.

## 2 Приклади посилань у тексті

Пошук відеоігор у GamesInfoSys виконується за допомогою зовнішнього каталогу RAWG [1].

Серверну частину реалізовано на ASP.NET Core Razor Pages [2], а доступ до локальної бази даних виконується через Entity Framework Core [3].

Для перерахунку магазинних цін використовується офіційний сервіс курсів Національного банку України [4].

Структуру характеристик якості доцільно формувати за моделлю ISO/IEC 25010 [5].
