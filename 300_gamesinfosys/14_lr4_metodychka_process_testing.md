# ЛАБОРАТОРНА РОБОТА 4. ПРОЦЕС ТЕСТУВАННЯ GAMESINFOSYS

Джерело-основа: `Лабораторна робота 4 (1).docx`.

## Мета

Визначити види і техніки тестування, застосувати їх до GamesInfoSys та оформити результати.

- інтеграційне;

- приймальне;
- перевірка взаємодії;
- негативне.

### Нефункціональні

- smoke;

- build verification.

## Рекомендовані техніки

| Техніка | Приклад GamesInfoSys |
|---|---|
| класи еквівалентності | числовий ID, Steam URL, сторонній URL |
| граничні значення | порожній запит, дуже довгий запит |
| таблиця рішень | API key є/немає, мережа є/немає |
| переходи станів | нова пропозиція, наявна, оновлена |
| сценарне тестування | пошук - картка - пропозиція |
| дослідницьке | незвичні назви, відсутні поля |

## Завдання

1. Виконати `dotnet build`.
2. Провести smoke.
3. Перевірити каталог у demo-режимі.
4. Перевірити пошук.
5. Перевірити Steam ID.
6. Перевірити SQLite.
7. Перевірити зовнішню помилку.
8. Перевірити мову.
9. Провести регресію.
10. Описати дефекти і висновки.
