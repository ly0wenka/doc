# Use Case GamesInfoSys

Діаграма побудована за правилами Visual Paradigm: актори показані поза функціями системи, use cases описують зовнішньо видиму поведінку `GamesInfoSys`, комунікаційні зв'язки показують взаємодію акторів із функціями системи. У VP-файлі межу системи не залито контейнером, бо імпортований `System Boundary` перекриває підписи елементів; для документа межу можна додати вручну як прямокутник навколо use cases.

## Актори
- Користувач
- RAWG API
- Steam / CheapShark
- Prom.ua / OLX
- НБУ

## Основні use cases
- Шукати відеоігри
- Переглядати картку гри
- Отримувати метадані гри
- Оновлювати пропозиції магазинів
- Перераховувати ціни у гривню
- Уточнювати Steam App ID
- Переходити до магазину
- Змінювати мову інтерфейсу
