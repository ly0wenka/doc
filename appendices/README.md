# Додатки до роботи GamesInfoSys

- `dodatok_a_grafichni_materialy.md` - IDEF0, IDEF3, DFD та UML-моделі за структурою графічного додатка у зразку Чуба.
- `dodatok_b_programnyi_kod.md` - фактичний лістинг розробленого застосунку за структурою програмного додатка у зразку Леонова.
- `dodatok_c_protokol_testuvannya.md` - сценарії перевірки, результати та скриншоти інтерфейсу.

Файли А і Б формуються командою з кореня проєкту:

```text
.\scripts\build_markdown_appendices.cmd
```

Усі текстові файли записуються в UTF-8 без BOM.
