# Матеріали до захисту GamesInfoSys

## Презентації

- `presentation/01_gamesinfosys_chub_style.md` - розгорнута презентація за композицією PDF-зразка Д. О. Чуба.
- `presentation/02_gamesinfosys_leonov_style.md` - компактна презентація за композицією PDF-зразка І. О. Леонова.
- `presentation/assets/` - реальні скриншоти розробленого застосунку.

## Додатки

- `appendices/dodatok_a_grafichni_materialy.md` - IDEF0, IDEF3, DFD та UML-діаграми.
- `appendices/dodatok_b_programnyi_kod.md` - фактичний програмний код GamesInfoSys.
- `appendices/dodatok_c_protokol_testuvannya.md` - протокол тестування та ілюстрації.

Матеріали не копіюють предметну область прикладів. Їхню структуру та логіку оформлення адаптовано до теми інформаційного ресурсу відеоігор і до фактичної реалізації GamesInfoSys.
